## Como compilar e executar

Com o [GCC](https://gcc.gnu.org/) instalado:

```bash
gcc "Unidade 1/Capítulo 1/Atividade_1.c" -o atividade1
./atividade1
```

> No Windows, execute com `atividade1.exe`.
> 
> Programas que leem ou gravam arquivos (Capítulo 4) devem ser executados a partir da pasta do próprio capítulo, pois usam caminhos como `./partidas.txt`.
> 
> No Capítulo 7 é necessário adicionar também `agenda.c`: `gcc Atividade_41.c agenda.c -o atividade41`.
